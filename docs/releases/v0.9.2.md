# 小幕 v0.9.2 · 核心性能与内存深度优化

本版本聚焦高频交互、大结果集聚合、网络连接复用与解析器内存占用优化，显著降低界面单帧开销与 GC 压力，不改变现有功能行为与本地数据格式：

- **搜索与首页万条结果聚合优化**：结果去重表改用结构化站点键（避免为每条视频拷贝长 `Site.Ext` 字符串），大结果集排序由 `O(N log N)` 改为 `O(N)` 3-桶稳定分区并复用单次标题归一化结果；中文片名归一化新增零分配快路径；万条结果聚合耗时降低约 4.9×、临时内存分配减少约 77%。
- **详情 / 播放 / 直播 / 追剧每帧热路径优化**：
  - 详情页与播放页右侧面板查找同名候选改为 `O(1)` 索引定位，并预计算排序键，消除 60fps 弹幕播放期间每帧扫描万条搜索结果的开销（万条搜索背景下提速约 43×）。
  - 缓存直播频道分组与筛选结果、顶部搜索联想列表、弹幕高能曲线路径、当前分集下标及追剧历史标题索引；分集编号解析改为无正则零分配；海报缓存命中检查提前至 URL 解析前，零分配返回。
- **播放历史页虚拟化**：播放历史改用 `ui.List` 虚拟化渲染并改用当日时间戳边界分组，200 条历史单帧耗时降低约 9×、内存分配减少约 96%，同时避免历史超过 128 条时打穿海报缓存导致反复下载解码。
- **HTTP 连接池与解析器优化**：
  - 弹幕模块共享底层 HTTP 连接池，消除每次搜索/切集克隆新连接池的空闲连接泄漏与重复 TLS 握手；360 详情缺失回退改为最多 4 并发拉取。
  - 修复关闭 XBPQ 站点时误清进程级共享 Transport 空闲连接的问题；`drpy` 请求复用共享 `http.Client`。
  - CMS 响应改为前 14 字节零分配 HTML 检测与直接 `[]byte` 解码，消除整包大小写拷贝与多余字节/字符串复制；优化弹幕文本清洗与分片合并预分配、`pdfh` 多分支 `||` 共享单次 HTML DOM 及 XBPQ 懒解析。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.2.dmg` 或 `xiaomu-0.9.2-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.9.2-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.9.2-arm64.exe`。
- 已安装 v0.9.1 及更早版本的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
