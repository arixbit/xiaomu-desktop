# 小幕 v0.9.3 · 片源与直播配置本机缓存修复

本版本为紧急修复版，解决已导入的临时配置链接在失效（如返回 HTTP 404）后重启软件或进入直播页报错不可用的问题：

- **导入配置与直播列表本机缓存**：
  - 导入影视配置（单仓、多仓及已加载子线路）和独立直播源成功后，自动在本机用户数据目录以私有权限原子保存配置与频道快照（`source-config.json` / `source-live.json`）。
  - 下次启动或切换至「直播」页时直接从本机缓存恢复，不再每次联网重新拉取原配置链接；即便原临时分享链接已失效，已导入的点播配置和直播频道列表仍可持续使用。
- **手动刷新与失败回退**：
  - 在「片源」页直播源卡片补充「刷新直播」按钮，与「刷新配置」保持一致。
  - 仅在用户主动点击「刷新配置」/「刷新直播」或重新导入时才联网拉取；若远程链接返回 404 或网络不可达，提示错误但保留当前与本机已缓存的可用配置和频道。
- **兼容与隔离清理**：
  - 从 v0.9.2 及更早版本升级时，若本机尚未生成缓存文件（或缓存损坏），自动回退联网读取并在成功后补建本机缓存。
  - 移除片源或移除直播源时仅清理对应缓存文件，互不影响；移除独立直播源后可无缝回退到影视配置自带的直播缓存。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.3.dmg` 或 `xiaomu-0.9.3-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.9.3-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.9.3-arm64.exe`。
- 已安装 v0.9.2 及更早版本的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
