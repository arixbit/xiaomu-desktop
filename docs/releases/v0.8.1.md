# 小幕 v0.8.1

修复部分视频播完后不自动播放下一集的问题，并提高切集稳定性。

## 修复

- 部分 HLS 视频的实际结束时间与声明时长有细小差异，画面已经停止，播放器仍认为尚未播完。现在会在结尾前 250 毫秒内、进度连续 2 秒不变且没有暂停或缓冲时自动接着播放下一集。正常结束仍立即切集。
- 修复自动切集后控件继续读取已关闭的旧播放器、可能导致崩溃的问题。
- 自动下一集开关、最后一集、续播定位和片尾跳过保持原有行为；上一集的完成记录会保留，下一集失败后可重试或换线路。

## 安装与更新

支持 macOS 13 及以上，Universal 同时包含 Apple Silicon 与 Intel。可在应用内“检查更新”升级，或下载 xiaomu-0.8.1.dmg、xiaomu-0.8.1-macos-universal.zip 手动安装。

提供签名更新包、update-darwin-universal.json 和 SHA256SUMS，沿用原更新签名密钥。现有配置、追剧与历史数据保持兼容。App 沿用本地签名，尚无 Apple Developer ID 签名及公证。

## 验证范围

- go test ./...、go vet ./...、go test -race ./cmd/xiaomu 通过。
- 本机 AVPlayer 实播验证：本地生成的 HLS 末段声明时长增加 0.1 秒，修复前画面停止后不切集，修复后自动打开并实际播放第二集。
- 回归覆盖正常结束、结尾停滞、暂停、缓冲、进度及总时长变化、续播定位、关闭自动播放、最后一集、下一集解析失败和旧播放器释放。
- 本次未验证 Intel 实机或所有第三方片源。
