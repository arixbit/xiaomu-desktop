# 小幕 v0.9.7 · 全应用交互减负、文案统一与防误操作加固

本版本围绕「复杂留给系统，体验留给用户」原则，对桌面端全部页面、弹窗、播放控制与后台状态流进行系统性抛光与可靠性加固：

- **更省心的输入与自动判断**：
  - 自动清洗粘贴地址前后的空白及中英文引号、书名号、尖括号。
  - 「打开链接」支持直接粘贴 `rtsp://` / `rtmp://` 实时直播流，自动以直播模式（1× 倍速、隐藏网速与点播控制，且不误触 IPTV 频道故障切换）播放。
  - 长剧（50+ 集）进入详情页时自动定位到观看记录所在分集页并高亮续播集；侧边栏「追剧」新增新集红点，顶部搜索框新增一键清除按钮。
  - 区分健康跳过站点与不支持/禁搜站点，避免无意义提示「重试全部站点」；直播「上次观看」按来源 URL/内联标识严格匹配并核验已加载频道，自动隐藏已失效的续播条。
- **此刻无用即隐去，操作统一有回应**：
  - 单来源单线路单集影片隐藏无用的 320px 右侧选集栏（切换到仅有 1 集的备用线路且未播放时仍可点击）；全屏下隐藏无意义的「置顶」按钮并忽略 `P` 键。
  - 弹幕与字幕的「时间偏移」统一为左侧提前、右侧推迟及一致文案（`提前 Xs` / `推迟 Xs`）；无激活字幕轨或回退播放器下统一隐藏/禁用无效字幕偏移并拦截 `[` / `]` 快捷键。
  - 单片与多集在菜单、定时徽标与 OSD 反馈中统一区分「循环播放 / 播完本片」与「单集循环 / 播完本集」；补齐音轨、字幕、关闭字幕、画质切换、片头片尾打点与刷新/测速/追剧检查的明确完成反馈。
  - 跳过片头片尾按钮更名为「片头到这」「片尾从这」，放宽数字框宽度避免三位数裁切，并在关闭「自动下一集」时动态提示；弹窗自动聚焦地址框并支持 `640×420` 最小窗口滚动可达与 Tab 导航。
- **可撤销、防误删与不打断当前操作**：
  - 批量「清空历史」新增 5 秒一键「撤销」，且后台测速通知与后台刷新/保存错误会自动排队至撤销窗口之后，绝不覆盖撤销入口；按 `Esc` 可立即取消二段危险按钮确认。
  - 网盘「清理临时文件」升级为二段确认，明确展示实际目标目录（含自定义目录）与涉及网盘；夸克/UC 清理前每次从网盘根目录实时核验目录名，避免缓存目录 ID 失效或改名导致误删。
  - 取消 / `Esc` / 点遮罩关闭「更换片源」「更换直播源」时彻底隔离草稿并中止在途请求，空配置 `{}` 不会覆盖原脚本依赖目录；后台刷新配置停留在当前页，且不会打断正在播放或正在从历史恢复中的影片。
  - 修复取消收藏最后一个直播频道自动退回全部频道时的列表状态重置崩溃，补齐网盘分享/候选源鉴权续播的原片代际校验并消除网盘登录轮询潜在竞态。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.7.dmg` 或 `xiaomu-0.9.7-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel（内置通用 `libmpv.dylib`）。
- Windows x64 使用 `xiaomu-setup-0.9.7-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.2.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- 已安装 v0.9.6 及更早版本的 macOS 与 Windows x64 用户可以通过应用内“检查更新”直接升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
