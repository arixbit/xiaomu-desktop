# 小幕 v0.8.6 · 新版提醒

后台检查发现新版本后，侧边栏左下角的“检查更新”会变为“有新版本”，旁边显示提示圆点。悬停可以查看版本号，点击打开原生更新窗口，查看说明并选择安装。

选择“稍后提醒”后，侧边栏提示继续保留；选择“跳过此版本”后，隐藏该版本的提示。后台检查频率和安装方式沿用现有更新器：默认自动检查、由用户确认安装，自动下载仍需用户自行开启。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.8.6.dmg` 或 `xiaomu-0.8.6-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.8.6-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.8.6-arm64.exe`。
- 已安装 v0.8.5 的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

本版基于 v0.8.5，增加新版提示。弹幕仍在本地测试，未包含在本次正式发布中。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。
