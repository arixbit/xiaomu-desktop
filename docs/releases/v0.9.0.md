# 小幕 v0.9.0 · 升级 MyGo v0.10.0

本版本将底层桌面框架 MyGo 升级至正式版 `v0.10.0`，包含原生渲染、AVFoundation / Windows Media Foundation 视频播放稳定性、GPU 资源回收与界面交互等多项底层改进，同时保留 v0.8.7 的全部弹幕、点播换源、追剧与系统集成能力。

本版本暂不包含“内网盘（SMB/NAS）”功能及相关依赖；从 v0.8.7 升级的用户可直接使用，播放历史中遗留的内网盘条目会被自动忽略，不影响原有片库观看记录。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.0.dmg` 或 `xiaomu-0.9.0-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.9.0-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.9.0-arm64.exe`。
- 已安装 v0.8.7 及更早版本的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。
