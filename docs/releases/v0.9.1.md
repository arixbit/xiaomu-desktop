# 小幕 v0.9.1 · 底层优化与直播列表虚拟化

本版本结合 MyGo `v0.10.0` 新增能力，对海报内存占用、大型直播频道列表性能和搜索快捷键体验进行了精简优化：

- **海报缩略解码**：海报位图改用 `ui.DecodeBitmapScaled`（最长边 640px，不放大原小图），不再驻留原始压缩字节，大幅降低海量海报浏览时的内存占用，同时支持更高分辨率原图。
- **直播列表虚拟化**：直播页频道列表和播放页右侧频道面板改用 `ui.List` 虚拟化渲染，导入上千条 IPTV 频道时滚动、筛选和切换更流畅。
- **搜索快捷全选**：按 `⌘K` / `Ctrl+K` 聚焦搜索框时自动全选已有关键词，直接输入即可替换搜索内容。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.1.dmg` 或 `xiaomu-0.9.1-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.9.1-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.9.1-arm64.exe`。
- 已安装 v0.9.0 及更早版本的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
