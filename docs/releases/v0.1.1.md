# 小幕 v0.1.1

修正 v0.1.0 仍使用模板占位图标的问题，换为小幕正式图标：浅色幕布、深色底和红色播放按钮。macOS 安装包直接使用项目提供的多尺寸 `AppIcon.icns`，保留图标留白和阴影；开发运行的图标同步更新。

## 下载与安装

- 要求 macOS 13 或更新版本；Universal 同时包含 Apple Silicon 与 Intel。
- 下载 `xiaomu-0.1.1.dmg`，打开后将 `Xiaomu.app` 拖入“应用程序”，替换旧版。也提供 `xiaomu-0.1.1-macos-universal.zip`。
- 发布附件提供 `SHA256SUMS`。运行 `shasum -a 256 xiaomu-0.1.1.dmg`（ZIP 请替换文件名），与校验文件对应行比对。
- 本版仍为本地签名，尚无 Developer ID 签名及 Apple 公证。首次打开若被拦截，确认下载来源后到“系统设置 → 隐私与安全性”选择“仍要打开”。

本版仅更新图标和版本信息，功能及兼容范围见 [v0.1.0 发布说明](https://github.com/arixbit/xiaomu-desktop/releases/tag/v0.1.0)。当前采用默认浅色图标，尚未接入随系统外观切换的深色图标。
