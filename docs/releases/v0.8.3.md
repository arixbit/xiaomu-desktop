# 小幕 v0.8.3

减少快速重复搜索带来的CPU峰值、图片资源积累和大量搜索结果造成的界面停顿。

## 改进

- 同步脚本和模块执行响应取消；中断观察器在运行时释放前退出，取消后仍可正常复用引擎。脚本同时执行上限4，单运行时内存预算64MiB；搜索、首页、追剧和测速共享4个后台任务名额。
- 海报使用4个工作线程、32个排队名额；下载后先检查尺寸，缓存按编码数据、解码像素及缩略层预算控制在64MiB内。正常2048×2048图保留原尺寸；热图使用LRU保留，失败记录最多256条并过期清理。
- 合并搜索结果回写，每批只排序、分组一次；复用同查询存储，同时为详情保留独立快照。测速记录后台批量原子写入，关闭前完成保存。
- 配置替换、移除及关闭会取消测速；旧任务不能向新配置回写。

## 验证

Go 1.27.3，macOS 26.6.2，Apple M4 Max。原样全套测试256个顶层通过、含子测试429次通过，vet通过；普通全套中6项原生测试仍按原条件跳过，另用独立数据目录和合成媒体逐项启用，6项全部通过。既有测试及断言未改，新增14个顶层回归测试。

| 同一受控场景 | 修复前 | 修复后 |
|---|---:|---:|
| 20ms期限、有限200ms计算脚本 | 约199ms后成功返回 | 约22ms返回取消错误 |
| 实际同时执行的脚本 | 12 | 4 |
| 100个慢海报URL的活跃请求峰值 | 100 | 4 |
| 万条结果冷/热搜索响应p95 | 307.74 / 272.07ms | 12.64 / 12.63ms |
| 页面往返响应p95 | 279.47ms | 16.45ms |
| 同数据聚合10次累计分配 | 209.79MiB | 43.98MiB |

响应口径是主队列提交至下一次视图构建完成，不含物理输入到屏幕呈现；累计分配不是内存峰值。窗口负载为本地100站点、10000条结果，各50次冷/热搜索、滚动和页面往返。原生H.264、HEVC、HLS各30秒可见实播及关闭通过，短测不证明长期播放稳定。

## 已知限制

- 万条结果重复操作并自然静置30秒后，RSS增长44.14MiB，仍超过32MiB筛查线；此项已暂缓，不能宣称持续内存增长已解决，也未证实为泄漏。
- 一次历史测试事件循环提前退出的触发原因未明。旧诊断会将正常退出误报为主线程超时，已由独立对照确认；修正诊断不等于已找到该次退出原因。
- 未验证Intel实机、全部第三方脚本和长播稳定性；GPU/辅助进程的完整内存归属仍不充分。

## 构建与安装

支持macOS13+，Universal包含Apple Silicon和Intel。手动安装文件为xiaomu-0.8.3.dmg和xiaomu-0.8.3-macos-universal.zip；签名更新包、update-darwin-universal.json及SHA256SUMS一同准备。只有正式发布附件后，应用内更新才可获取本版。

沿用原应用标识、数据格式及更新公钥；不迁移或清除现有配置、历史和追剧记录。App使用本地ad hoc签名，未进行Apple公证。小幕不内置片源或默认配置。
