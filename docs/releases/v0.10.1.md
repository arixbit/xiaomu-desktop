# 小幕 v0.10.1 · 本地视频封面与播放修复

- **本地视频封面**支持自动匹配和手动选择，无需填写令牌。封面存入本机缓存，在首页「继续观看」和播放历史显示。识别为同一部剧的分集可复用封面，也可在设置里关闭自动匹配。
- **HLS 播放修复**解决 macOS 回退到系统播放器时的视频播放结束与循环问题。
- **图片缓存修复**来自 MyGo 上游，适用于从网络加载的图片。
- **应用更新加固**加强了解包检查，并要求 macOS 更新下载过程中的跳转继续使用 HTTPS。

## 下载与更新

- macOS Apple Silicon 使用 `xiaomu-0.10.1-arm64.dmg` 或 `xiaomu-0.10.1-macos-arm64.zip`。
- macOS Intel 使用 `xiaomu-0.10.1-amd64.dmg` 或 `xiaomu-0.10.1-macos-amd64.zip`。
- Windows x64 使用 `xiaomu-setup-0.10.1-amd64.exe`。
- Windows ARM64 使用 `xiaomu-setup-0.10.1-arm64.exe`。

正式发布后，可通过应用内「检查更新」升级。仍在使用 `v0.3.0–v0.9.7` macOS Universal 版本的用户会先升级到 `v0.9.8` 桥接版，重启后再升级到对应芯片的 `v0.10.1`。各下载附件可用 `SHA256SUMS` 校验。
