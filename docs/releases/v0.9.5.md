# 小幕 v0.9.5 · 修复百度网盘等官方网页登录跳转与授权校验

本版本为热修复更新，重点解决网盘官方网页登录弹窗在跨源跳转及第三方 OAuth 流程中的卡死问题：

- **修复网盘登录弹窗跨源跳转被拦截**：
  - 隔离登录窗口（`Untrusted`）原先未注册导航与子弹窗处理，导致百度网盘扫码确认后由 `pan.baidu.com` 跳转至 `passport.baidu.com` 被静默取消，页面停留在「扫描成功 请在手机端确认登录」。
  - 现已放行 `http`/`https`/`about:blank` 正常登录跳转并拦截 `baidunetdisk://`、`file://` 等非网页协议，支持同会话打开微信/QQ/微博等第三方 OAuth 子弹窗，同时覆盖阿里云盘、UC 网盘及夸克网盘的跨子域登录跳转。
  - macOS 登录窗口补充标准 Safari UA 后缀，避免被网盘服务端识别为裸 WebView 而降级。
- **改进网盘授权轮询与百度接口容错**：
  - 鉴权校验偶发失败不再永久跳过同一 Cookie/Token，间隔 4 秒后自动重试。
  - 百度网盘若已获取 `BDUSS` 但超过 3.5 秒未签发 `pan.baidu.com` 域的 `STOKEN`，自动跳转一次 `https://pan.baidu.com/disk/main` 完成握手。
  - 兼容百度接口未登录/报错时返回的数组字段（如 `{"errno":-6,"result":[]}`、`{"errno":-31,"extra":[]}`）及 HTML 登录页重定向，准确返回重新登录或空间不足提示。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.5.dmg` 或 `xiaomu-0.9.5-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel（内置通用 `libmpv.dylib`）。
- Windows x64 使用 `xiaomu-setup-0.9.5-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.2.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- 已安装 v0.9.4 及更早版本的 macOS 与 Windows x64 用户可以通过应用内“检查更新”直接升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
