# 小幕 v0.10.0 · Apple 级统一动效、进度条画面预览、优酷弹幕直连与 Windows ARM64

本版本全面重构桌面端与官网的动效体系，新增播放进度条悬停实时画面预览、影院深色悬浮舞台与原生失败路由卡、优酷公开直连弹幕与综艺精准匹配，并升级至 `mygo-player v0.5.2` 恢复 Windows ARM64 原生支持：

- **全项目 Apple 级统一动效语言与交互连续性**：
  - 全应用收敛为 5 个共享原语（`animSnap` / `animControl` / `animSurface` 临界阻尼弹簧、`animColor` Oklab 感知色过渡与 `animFade` 非位移动效淡入淡出），入场可打断且承接速度、离场更利落。
  - 统一详情页与同级页面到同一持久化 `shell-main` 与浮动工具栏，恢复详情推入/返回过渡与返回按钮入场，且保持工具栏几何精确不抖动；播放舞台进出增加平滑衔接。
  - 侧边栏、窄栏图标轨、下划线标签、直播分组与分段控件全面升级为弹簧滑移 `ElementTransition.Match` 指示条与滑块；全部 6 个弹窗补齐面板入场与独立 overlay 身份，弹层与提示启用边缘自动翻转感知（`Flip`）。
  - 进度条在保持 X 轴 0 延迟直接跟手的同时增加轨道/圆点弹性膨胀；全部折叠箭头支持 0°↔180° 平滑旋转；时钟、计数、倍速与倒计时全线启用等宽数字（`tnum`）与数字滚动过渡；背景模糊海报淡入移至父容器以保持模糊缓存命中；全面遵守系统「减弱动态效果」（含静态加载指示与长标题跑马灯静止），并消除空闲页无效重绘。
  - 官网同步升级深浅色 WCAG AA 高对比度按钮、窄屏手机适配、触屏悬停隔离与 `prefers-reduced-motion`。
- **播放进度条悬停实时画面预览**：
  - 悬停或拖动进度条时，在进度条与弹幕高能密度曲线上方展示 16:9 实时画面预览与垂直参考线，不中断主画面播放；仅在点击或有效拖动松手时提交单次 Seek，并支持键盘方向键、Enter 与 Esc。
  - 预览画面由独立静音/暂停 `mygo-player` 实例解码；远程流在首帧返回前先以紧凑时间胶囊呈现，配合回环代理 `?preview=1` 轻量直通（跳过多片预取与收紧空闲超时）、VOD/master m3u8 缓存与关键帧快进控制带宽占用。
- **影院深色 UI 焕新、悬浮播放舞台与失败路由卡**：
  - 全面打磨应用主壳、发现、详情、直播、历史、追剧与片源页的影院深色质感与暗色提示样式；播放页升级为悬浮播放舞台与右侧悬浮选集/换源面板（长来源与分集标题支持悬停平滑跑马灯）。
  - 播放失败浮层直接展示当前/失败来源与线路，支持就地重试（重复失败轻摇反馈）、同步切源/切线路、平滑展开技术详情与「已复制 ✓」自动复原；顶栏按钮提示自动落在顶栏下方避让窗口控制按钮；跳过片头撤销条明确显示精确跳过秒数。
- **Windows ARM64 原生支持恢复（`mygo-player v0.5.2`）**：
  - `mygo-player` 升级至 `v0.5.2`，同步提供 Windows x64 与 Windows ARM64 原生安装包与签名更新包，各自随包内置对应架构 `mpv-2.dll`。
- **弹幕优酷直连源、综艺匹配升级与字幕快速报错**：
  - 内置国内直连弹幕新增优酷（`v.youku.com` / `acs.youku.com`）公开弹幕源，补强综艺正片优先排序、过滤极短预告、自动消歧正片/加更/纯享/上下期以及日期分期与中英文季数识别。
  - 射手在线字幕接口遇到 HTTP 错误时不再等待完整响应体，立即返回错误提示。

## 下载与更新

- **macOS 13 及以上（按芯片分架构轻量包）**：
  - Apple Silicon（M 系列）下载 `xiaomu-0.10.0-arm64.dmg` 或 `xiaomu-0.10.0-macos-arm64.zip`。
  - Intel 下载 `xiaomu-0.10.0-amd64.dmg` 或 `xiaomu-0.10.0-macos-amd64.zip`。
- **Windows 10 / 11（x64 / ARM64，均内置对应架构 `mpv-2.dll`）**：
  - Windows x64 下载 `xiaomu-setup-0.10.0-amd64.exe`。
  - Windows ARM64 下载 `xiaomu-setup-0.10.0-arm64.exe`。
- **应用内自动更新**：
  - 已安装 `v0.9.8+`（macOS 分架构、Windows x64 或 Windows ARM64）的用户可通过应用内「检查更新」直接升级至 `v0.10.0`。
  - 仍停留在 `v0.3.0–v0.9.7` 的旧版 macOS Universal 用户，本版继续随附 2 KB 固定桥接清单 `update-darwin-universal.json`，应用内更新会自动先升至 `v0.9.8` 桥梁版、重启后再自动升级至对应芯片的 `v0.10.0` 轻量单架构包。
- 全部安装包与签名更新包均附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
