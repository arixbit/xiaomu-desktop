# 小幕 v0.8.4

首个 Windows 版本，提供 x64 和 ARM64 安装包。可以导入自己的影视配置，搜索片名并选集播放，也可以导入 IPTV 列表或直接打开视频链接。

## Windows

- 最小化、最大化、还原和关闭按钮使用白色图标，在深色界面上清晰可辨。
- 启动、还原和退出全屏时，窗口会调整到显示器可用桌面范围内。
- 支持 Windows 本地路径、文件关联和 `xiaomu://` 链接。
- 每个用户单独安装。卸载按安装文件清单清理，保留安装目录中的其他文件。

## 下载

- Windows x64 使用 `xiaomu-setup-0.8.4-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.8.4-arm64.exe`。
- macOS 13 及以上使用 `xiaomu-0.8.4.dmg` 或 `xiaomu-0.8.4-macos-universal.zip`，包含 Apple Silicon 和 Intel 架构。
- 使用随附的 `SHA256SUMS` 核验下载。应用内更新仍沿用现有 Ed25519 公钥。

Windows 安装器未做 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。macOS 应用使用本地 ad hoc 签名，尚无 Apple 公证。

Windows 安装、片源导入、MP4 和 HLS 播放、全屏和卸载已在 Windows 11 x64 预览包上验证。ARM64 和 Windows 10 尚缺运行验证。
