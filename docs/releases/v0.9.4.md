# 小幕 v0.9.4 · 全格式原生播放、本地弹幕、聚合网盘原画与失效源过滤

本版本集成独立社区插件 `mygo-player v0.2.1`（`libmpv` LGPL-2.1+，零 cgo），带来跨平台全格式本地与网盘原画播放体验：

- **全格式原生播放引擎（macOS 通用 + Windows x64）**：
  - macOS（Apple Silicon / Intel）通过 VideoToolbox + Metal 零拷贝渲染；Windows x64 通过 D3D11VA + `ui.Bitmap` 合成渲染，弹幕与玻璃控件叠加无遮挡（Windows ARM64 自动平滑回退系统播放器）。
  - 原生直解 MKV / MP4 / MOV / WebM / FLV / TS / M2TS / AVI 等容器；播放底栏新增「音轨」与「字幕」菜单，支持多音轨热切换、内封字幕切换以及 `.srt` / `.ass` / `.ssa` / `.vtt` / `.sup` 外挂字幕（文件选择或直接拖拽加载）。
- **独立本地视频播放与本地弹幕**：
  - 即使未导入任何影视配置，也可通过侧边栏「打开文件」、欢迎页「打开本地视频」、菜单栏 `⌘O` / `Ctrl+O` 或拖拽视频文件（支持视频+字幕同时拖入）直接播放。
  - 本地文件同步开放弹幕能力：支持按文件名自动清理标签匹配弹幕、手动修改片名/集数搜索、`D` 键快捷开关与高能进度曲线。
- **聚合网盘与 AList 原生支持**：
  - 无需 Android Jar，原生支持用户配置中的 `AList`、`csp_*Share` 分享清单及明文网址网盘站，也支持在「打开链接」直接粘贴网盘分享链接。
  - 支持夸克网盘、UC 网盘、阿里云盘、百度网盘官方网页自动登录授权，凭证以 `0600` 权限仅保存在本机。
  - 夸克 / UC / 百度默认直接拉取原画直链播放（移除多余的「流畅转码」选项）；转存前自动复用或清理临时目录，并在夸克 / UC 上定向清除本次删除临时文件的回收站记录，避免大体积 4K 文件占满空间。
- **网盘搜索提速与无效站点自动过滤**：
  - 网盘与 AList 站点在全网搜索中提升至最高优先级、跳过首页抓取并并发探测搜索路径；「片源」页直接汇总已识别的网盘 / AList 站点，详情页新增网盘标识与「相近结果」入口。
  - 首页扫描、手动测速或打开站点失败（含停靠空壳页）时自动过滤失效站点并在普通搜索中跳过；支持按需展开查看失效站点，点击「重新测速」或「刷新配置」可重新检测恢复。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.4.dmg` 或 `xiaomu-0.9.4-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel（内置通用 `libmpv.dylib`）。
- Windows x64 使用 `xiaomu-setup-0.9.4-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.2.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- 已安装 v0.9.3 及更早版本的 macOS 与 Windows x64 用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
