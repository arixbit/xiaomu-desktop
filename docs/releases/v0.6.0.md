# 小幕 v0.6.0

重排影片详情页，让播放与选集更容易找到；根据实际请求耗时排列来源，优先尝试响应较快的站点。

## 更新内容

- **详情页**：放大海报，固定影片信息和“立即播放”按钮。来源卡片在独立区域内滚动，保留来源总数、当前来源及失败状态；简介去掉 HTML 标签并还原常见转义字符。
- **来源耗时与排序**：记录搜索和读取详情时的实际请求耗时，在来源卡片上显示。已测量的来源按耗时升序排列，未测量的来源保留原顺序，当前影片读取失败的来源排在最后。
- **本机记录**：保留最近的站点耗时记录，重启后恢复；缓存命中不计作测速，不额外发送测速请求。这里测量的是接口响应耗时，不代表视频下载带宽或实际播放流畅度。
- **窗口拖动**：工具栏、侧边栏空白处和播放页标题区域支持拖动，移除额外顶部拖动条；双击可最大化，全屏时关闭拖动，按钮和输入框仍可正常操作。

## 安装与更新

macOS 13+，Universal 同时包含 Apple Silicon 与 Intel。安装文件为 `xiaomu-0.6.0.dmg` 或 `xiaomu-0.6.0-macos-universal.zip`，附 `SHA256SUMS`。

本版沿用现有更新签名密钥，提供签名更新包和更新清单。在线更新需待 GitHub 正式发布本版后可用；本地安装包可直接手动安装。App 仍为本地签名，尚无 Developer ID 签名或 Apple 公证。

## 验证与限制

- 在 Apple Silicon Mac 上通过 `go test ./...`、`go vet ./...` 和 `go test -race ./cmd/xiaomu ./internal/library`；双架构与签名核对结果见产物目录中的 `build-receipt.json`。
- 详情页布局、来源耗时排序与窗口拖动区域有 headless 回归测试；本次未进行真机交互、实际播放或 Intel 实机验证。
- MyGo 首次读取媒体信息仍可能同步阻塞界面；无上游响应的单次等待限制为 30 秒。
