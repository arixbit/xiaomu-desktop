# 小幕 v0.2.0

这次更新重新整理了浏览和播放流程，并加入本机播放历史与断点续播。小幕仍为 macOS 原生播放器，不内置片源、默认配置或真实片源地址。

## 更新内容

- 侧边栏统一为“首页”“直播”“播放历史”“片源”，顶部搜索框跨站搜索，返回按钮逐级返回；视频直链改从“打开链接”导入。
- 同名影片合并显示并标出来源数。独立详情页提供来源、线路和分集选择，某个来源读取失败时尝试其他来源。
- 增加播放历史，保存上次观看的分集和进度；点“继续播放”重新解析媒体地址并接着看，已看完的分集可继续下一集。历史只存在本机，可移除或清空，片源已移除的记录会标记为不可用。
- 播放页可切换来源或线路并保留观看位置，失败时提供重试及切换入口；选集、来源和直播频道使用独立面板。
- “片源”页集中导入、刷新、移除配置及单站分类浏览；首页推荐和搜索分别保留状态，后台任务按用途独立取消。
- 保留正式小幕图标、Glass 界面及原有 CMS、脚本规则、网页取流和 IPTV 支持。

## 下载与安装

- 要求 macOS 13 或更新版本；Universal 包含 Apple Silicon（arm64）与 Intel（x86_64）。
- 下载 `xiaomu-0.2.0.dmg`，打开后将 `Xiaomu.app` 拖入“应用程序”替换旧版；也提供 `xiaomu-0.2.0-macos-universal.zip`。
- 附件提供 `SHA256SUMS`。运行 `shasum -a 256 xiaomu-0.2.0.dmg`（ZIP 请替换文件名），与校验文件对应行比对。
- 本版使用本地签名，尚无 Developer ID 签名及 Apple 公证。首次打开若被拦截，确认下载来源后到“系统设置 → 隐私与安全性”选择“仍要打开”。

## 验证与限制

- `go test ./...` 与 `go vet ./...` 通过；任务取消、搜索切换、同名影片合并、播放历史和续播路径通过针对性竞态检查。
- 本机原生 AVPlayer HLS 验证通过：持续解码变化画面、播放进度推进，分片请求保留所需请求头。该检查使用本地生成的测试视频，不代表任意第三方片源都可播放。
- Intel 版本提供编译产物，尚未在 Intel Mac 上实机验证；HEVC 及其他编码未全面验证。
- 不执行 Android jar/Dex 或 Python 爬虫；HTTP-FLV 转换、RTSP/RTMP、直播节目单及回看尚未提供。收藏和云同步尚未提供。
