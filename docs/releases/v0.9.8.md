# 小幕 v0.9.8 · 豆瓣全品类热播、跨站并发加速与 macOS 分架构轻量包

本版本带来首页全品类豆瓣热播与下滑无限翻页、跨站搜索与进详情并发加速、详情页切源头部防闪烁，并将 macOS 正式包拆分为 `arm64` / `amd64` 轻量单架构包（体积约减半）：

- **首页豆瓣全品类热播与下滑自动翻页**：
  - 首页顶部标签由 3 项扩充为 9 项：**实时热门 · 热门电影 · 热门剧集 · 热门综艺 · 热门动漫 · 热门短剧 · 热门纪录片 · Top 250 · 最近更新**，默认落到全品类当季「实时热门」。
  - 接入豆瓣新版官方热榜接口（含官方「热门短剧」`tv_short_drama`、自动过滤非影视条目、Top 250 显示 `#排名 · 豆瓣评分`、各榜独立 6 小时磁盘缓存）。
  - 支持下滑接近底部自动加载下一页（超高无滚动条大屏保留手动兜底按钮、失败不循环重试），各标签独立记忆滚动位置，较窄窗口自动折行或横向滑动防止标签裁切。
  - 全部 8 个豆瓣榜单缓存自动联动详情页评分、搜索建议与片库「最近更新」热播排序（不混入 Top 250 经典老片）。
- **跨站搜索与进详情并发加速**：
  - 前后台与重型脚本三池分流：后台静默任务（首页最近更新、追剧检查、测速）保持 4 并发；前台主动搜索与点海报查源独享 10 路高并发且单站超时收紧至 8 秒，不再排队等待后台慢站；重型脚本站（`drpy2` / `FongMi` / `XBPQ`）单独限 4 并发，把其余槽位留给轻量 HTTP 站。
  - 偏好与快站优先调度：优先请求上次成功播放过该片的偏好站与 `a.latency` 中历史响应最快的站，大幅缩短首源命中时间。
  - 详情页自动选源 1.5 秒慢源补位竞速：自动打开候选来源时，若首源 1.5 秒内未响应则并发拉起第 2 候选竞速，谁先成功立刻展示并取消另一路、安全关闭迟到会话；首源快时不产生多余请求。
- **详情页切源稳定不闪烁**：
  - 将详情页顶部影片资料与下方来源选集解耦：进入详情时已有的海报（如豆瓣海报）锁定不被其他站糊图覆盖；年份、类型与简介按“只补缺、不降级覆盖”原则固定保留，切换来源（含播放页换源）只切换线路与分集。
- **播放器底座升级与界面统一**：
  - `mygo-player` 升级至 `v0.5.1`，统一播放页菜单按钮样式并补齐原生播放回归测试。

## 下载与更新

- **macOS 13 及以上（按芯片分架构，体积约减半）**：
  - Apple Silicon（M 系列）下载 `xiaomu-0.9.8-arm64.dmg` 或 `xiaomu-0.9.8-macos-arm64.zip`。
  - Intel 下载 `xiaomu-0.9.8-amd64.dmg` 或 `xiaomu-0.9.8-macos-amd64.zip`。
- **Windows x64**：下载 `xiaomu-setup-0.9.8-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.5.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- **应用内自动更新与无感过渡**：
  - 已安装 `v0.3.0–v0.9.7`（macOS Universal 或 Windows x64）的用户均可通过应用内「检查更新」直接升级至 `v0.9.8`。
  - 本版作为 macOS 分架构切换的**过渡桥梁版**，同时附带 `xiaomu-0.9.8-darwin-universal.tar.gz` 与 `update-darwin-universal.json` 供旧版自动更新；升到 `v0.9.8` 后，应用内置的按芯片自适应更新源会在后续版本自动切换并拉取各自芯片的轻量单架构包（`arm64` / `amd64`），无需手动重装。
- 全部安装包与签名更新包均附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
