# 小幕 v0.3.1

修复播放页缺少键盘操作的问题。v0.3.0 用户可在侧边栏或“小幕”菜单点击“检查更新”直接安装。

## 播放快捷键

- **空格**：暂停／继续，长按不会连续切换。
- **左／右方向键**：快退／快进 10 秒，停在视频开头或结尾；暂停时跳转仍保持暂停。直播与时长未知的视频不快进。
- **Esc**：退出全屏，保留当前视频和播放状态；首页全屏时也有效。

全屏控件隐藏时这些按键仍生效，操作后会显示控件。点击“全屏”后焦点回到视频；输入框、弹窗和聚焦控件保留自己的键盘操作，弹窗中的 Esc 优先关闭弹窗。

## 验证

- `go test ./...` 与 `go vet ./...` 通过。回归覆盖快进边界、长按、隐藏控件、输入框与弹窗。
- 本机通过独立原生窗口和本地生成的静音视频验证：原生按键事件控制真实 AVPlayer 暂停／继续、前后跳转 10 秒，Esc 退出 macOS 全屏并继续播放；点击全屏后按空格也能暂停。测试不使用用户片源。

## 下载与安装

macOS 13+，Universal 包含 Apple Silicon 与 Intel。可在线更新，也可下载 `xiaomu-0.3.1.dmg` 或 `xiaomu-0.3.1-macos-universal.zip`，将 `Xiaomu.app` 移入“应用程序”替换旧版。v0.2.0 及更早版本需手动安装。

附件包含签名更新包、更新清单与 `SHA256SUMS`。仍使用与 v0.3.0 相同的更新签名密钥；尚无 Developer ID 签名或 Apple 公证。Intel 尚未实机验证。
