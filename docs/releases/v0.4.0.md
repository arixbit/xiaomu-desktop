# 小幕 v0.4.0

加入本机收藏、点播失败恢复和播放偏好记忆，让想看的影片更容易找回，播放失败后可从原分集、原进度重试或换线路。

## 更新内容

- **收藏／想看**：影片详情页可“加入想看”，侧边栏“收藏”可打开或移除。收藏与播放历史独立，只保存在这台 Mac；原来源失效时尝试搜索当前片库，移除片源不会删除收藏。
- **点播恢复**：解析失败，或等待画面／缓冲停滞超过 30 秒后，提供重试、换线路及可用的换来源入口。保留失败的分集和续播位置，包括尚未完成的异步跳转。
- **播放偏好**：保存音量、点播播速及自动下一集开关，重启和切集后恢复。直播使用正常速度，切回点播恢复所选倍速。
- **媒体超时保护**：本地代理为上游响应及每次读取增加 30 秒超时，持续传输的视频和直播不受总时长限制。

## 安装与更新

macOS 13+，Universal 同时包含 Apple Silicon 与 Intel。安装文件为 `xiaomu-0.4.0.dmg` 或 `xiaomu-0.4.0-macos-universal.zip`，附 `SHA256SUMS`。

本版沿用现有更新签名密钥，并提供签名更新包和清单。正式发布后，v0.3.0 及以上用户可从 App 内“检查更新”安装；v0.2.0 及更早版本需手动安装。App 仍为本地签名，尚无 Developer ID 签名或 Apple 公证。

## 验证与限制

- `go test ./...`、`go vet ./...` 与 `go test -race ./cmd/xiaomu ./internal/proxy` 通过。
- 本机 Apple Silicon 使用本地生成的短视频验证 HLS、H.264、HEVC 的原生连续画面、进度推进、超时后换线路、续播及请求头保留。收藏页和详情页检查了 640 与 1120 像素窗口布局。
- 当前 MyGo 首次读取媒体信息仍可能同步阻塞界面；无上游响应的单次等待已限制为 30 秒。实际音频听感、长时间播放、睡眠唤醒和 Intel 实机仍待验证。
