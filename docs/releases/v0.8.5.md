# 小幕 v0.8.5 · 播放中换源

当前线路播不了时，打开“换源与选集”，点来源名称就能切到已知的其他来源。面板会列出该来源的线路和分集。只有一个已知来源时直接显示站名。

新来源有同名或同编号的分集时，会从原进度继续播放。找不到对应分集时可以手选，线路打不开时也可以在面板里直接换一条。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.8.5.dmg` 或 `xiaomu-0.8.5-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.8.5-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.8.5-arm64.exe`。
- 已安装 v0.8.4 的用户可以在应用内检查更新。手动下载的文件可用随附的 `SHA256SUMS` 核验。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。
