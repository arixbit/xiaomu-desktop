# 小幕 v0.7.0

首页直接接着看，追剧更新更容易找到，并按剧记住跳过设置和好用的播放来源。

## 新功能与改进

- **继续观看**：首页显示最近 6 部影片的海报、分集和进度，点击直接续播。“从这里移除”保留播放历史，再次播放后恢复首页入口。
- **追剧**：原收藏升级为追剧，显示观看进度、最新分集和新集标记。启动或手动刷新时检查用户已导入的来源，可继续观看或看下一集；失败和空响应保留已知更新。
- **本剧跳过**：在播放页“跳过”面板设置片头、片尾秒数，后续分集沿用，可随时关闭。片尾仅在开启自动下一集且存在下一集时生效。
- **来源记忆**：优先使用同剧上次实际播放成功的站点和线路。只有原生播放进度推进后才记成功；续播严格匹配同剧同集，记忆来源缺集或解析失败时回退原历史来源，播放中仍可手动换源。
- **首页与搜索**：根页面隐藏“返回”，搜索框在内容区居中，窄窗口独占一行。`⌘K` 聚焦，`Esc` 依次关闭联想、退出输入、返回上一级。
- **详情页**：来源、线路和选集使用分层折叠，影片信息与播放入口固定在顶部。

## 安装与更新

macOS 13+，Universal 同时包含 Apple Silicon 与 Intel。可通过 App 内“检查更新”升级，或下载 `xiaomu-0.7.0.dmg` / `xiaomu-0.7.0-macos-universal.zip` 手动安装。

同时提供签名更新包、`update-darwin-universal.json` 和 `SHA256SUMS`。现有收藏及历史数据保持兼容。App 使用本地签名，尚无 Apple Developer ID 签名及公证。

## 验证

- Apple Silicon Mac 上 `go test ./...`、`go vet ./...` 和 `go test -race ./cmd/xiaomu ./internal/library` 通过。
- 使用本地生成的 H.264 / HEVC 视频通过 AVPlayer 连续解码、续播、请求头保留及播放偏好测试；片头跳过、实际播放来源记忆和片尾跳过后进入第 2 集均通过。
- 自动化回归覆盖持久化、隐藏续播入口、严格分集匹配、追剧刷新失败与取消，以及窄窗口布局。
- 未在本次发布中验证 Intel 实机、用户实际片源、音频听感或完整桌面人工操作。
