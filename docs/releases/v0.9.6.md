# 小幕 v0.9.6 · 桌面深度播控、在线字幕、IPTV 节目单回看与全格式本地闭环

本版本带来面向 macOS 与 Windows x64 桌面观影场景的全面体验升级、性能减负与核心缺陷收口：

- **明暗双主题与桌面交互抛光**：
  - 全面适配浅色/深色系统外观与减弱透明度、高对比度、减弱动态效果无障碍偏好；窄窗自动切换紧凑图标侧边栏，统一页面/弹窗/按钮/卡片动效。
  - 删除单条历史或追剧支持一键「撤销」，清空/移除片源/退出账号等危险操作改为 4 秒二次确认防误触；自动跳过片头新增「回看片头」入口，片尾自动连播新增倒计时与「暂不连播」取消浮条。
  - 补齐 `M` 静音、上下方向键调音量、`F` 切换全屏及居中操作 OSD 反馈。
- **桌面观影与 `libmpv` 深度播控**：
  - **置顶迷你小窗**：播放页顶部提供「置顶」（`P`）与 480×270「小窗」（`T`），顶部自带拖动区、悬停显示精简控制条，退出或离开播放自动恢复原窗口尺寸与置顶状态。
  - **字幕体验与在线匹配**：支持 `[` / `]` ±0.5s 字幕时间偏移、字号缩放、垂直位置与中文轨自动优先；内置免登录射手（Shooter）本地文件 4 块 MD5 哈希匹配（仅传纯文件名与哈希），并支持用户自填伪射手（ASSRT）Token 按片名检索、ZIP 内存安全择优解压与一键挂载。
  - **画面与高级操控**：支持画面比例/铺满裁切、90° 旋转（`R`）、单集循环（`L`）、长按右方向键 2× 临时倍速、一键 PNG 截图（`S`，防覆盖唯一命名）、播放信息浮层（`I`，展示编码/帧率/硬解状态）与定时关闭（15/30/45/60 分钟或播完本集）。
- **IPTV 直播进阶体验**：
  - 支持渲染台标 `tvg-logo`（无台标展示首字徽标）、常用频道 `☆`/`★` 收藏置顶与专属分组、以及直播页顶部「上次观看」一键恢复（跨源自动切换）。
  - 新增 XMLTV（含 `.xml.gz` 自动解压）与 TVBox/DIYP 双协议 EPG 节目单，频道行与标题栏实时展示正在播出节目，右侧面板支持「频道｜节目单」切换与往期节目一键「回看」（回看支持进度条/方向键快进、倍速及一键「返回直播」）；M3U `x-tvg-url` EPG 随本机缓存持久保存。
  - `libmpv` 后端直播放开 `rtsp://` / `rtmp://` 直连，并修复本地回环代理 chunked HTTP-FLV 实时流逐块刷新。
- **本地视频完整闭环**：
  - 系统文件关联扩展至全部常见视频容器（`mp4`、`mkv`、`mov`、`m4v`、`m3u8`、`webm`、`flv`、`ts`、`m2ts`、`avi`、`wmv`、`mpg`、`mpeg`、`rmvb`、`3gp`、`ogv`）。
  - 本地视频支持自动加载同目录伴随字幕、保存播放历史并进入首页「继续观看」、自动扫描同目录剧集并提供「目录列表」选集与播完自动连播。
- **性能与可靠性修复**：
  - 弹幕 60fps 渲染改用 `ui.ShapeText` + `p.TextLayout` 排版缓存；海报加载迁移至 MyGo `ui/netimage`（获得跨重启磁盘缓存与离屏取消，保留豆瓣限定 Referer 与尺寸预算）。
  - 修复失效站点过 30 分钟 TTL 冷却后二次失效无法刷新时间戳的问题；缓存播放历史本地文件检查，避免渲染每帧反复 `os.Stat`；CI 扩展至 Linux / macOS / Windows 三平台矩阵。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.9.6.dmg` 或 `xiaomu-0.9.6-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel（内置通用 `libmpv.dylib`）。
- Windows x64 使用 `xiaomu-setup-0.9.6-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.2.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- 已安装 v0.9.5 及更早版本的 macOS 与 Windows x64 用户可以通过应用内“检查更新”直接升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
