# 小幕 v0.9.9 · 影院深色播放页、HTTP 性能调优与切源可靠性修复

本版本带来全新统一影院深色视觉与重设计的播放页交互，全面调优外部 HTTP 连接池与重复请求开销，并修复播放页跨源/切线路（含 4K 网盘切 1080P）与详情页稳定性问题：

- **影院深色视觉与播放页重构**：
  - 全应用统一锁定为影院深色外观与珊瑚品牌强调色，避免明暗切换带来的视觉割裂。
  - 重设计播放页顶部 HUD、底部控制栏、倍速/字幕/弹幕/更多浮层、右侧选集/跳过/直播/同目录面板及迷你小窗控件，新增真实画面分辨率角标（`8K` / `4K` / `2K` / `1080P` 等，点击查看完整播放信息）。
  - 同步优化主界面返回按钮、侧边栏图标比例、继续观看移除按钮，以及首页豆瓣榜单标签在宽字体/窄窗下的折行与时间戳布局。
- **播放页切源 / 切线路可靠性修复**：
  - 增强 `matchEpisode` 归一化集数匹配，支持网盘原画文件名（如 `S01E02`、`EP02`、`第02集 4K`、` - 02 [1080p]`）与常规 CMS 分集（`第02集`、`02`）互配；单集电影在跨来源/跨线路切换（如 4K 原画切 1080P 正片）时自动切换并保留播放进度。
  - 切源或切线路失败、无可用线路、未匹配到当前分集时弹出清晰 OSD 提示，并在侧栏显示醒目状态卡片（标明「仍在播放：原来源 · 原线路」与一键「回到当前」按钮）；允许在下拉菜单直接重选失败来源重试；同来源切到未匹配线路时取消在途解析任务；重置切集后分集索引缓存，避免界面已切但画面仍停留在旧视频。
- **全链路 HTTP 性能调优与请求去重**：
  - 引入 `internal/httpx` 统一外部 HTTP 客户端：保留系统代理/PAC，放宽连接池配额（`MaxIdleConns=128`、`MaxIdleConnsPerHost=16`、`MaxConnsPerHost=64`），显式设置连接/TLS/空闲超时，通过有界 `DrainAndClose` 保障 HTTP/1.1 Keep-Alive 连接复用，按 `Content-Length` 预分配响应读取缓冲区，并内置 `httptrace` 慢请求（`>=500ms`）脱敏结构化日志。
  - 多仓失效子线路新增 10 分钟冷却（首页、搜索与追剧刷新共享，手动刷新清空），`config.Read` 增加引用计数并发合并（singleflight），跳过确定 HTTP `404` / `403` / `502` 的无效 HTTPS 回退。
  - `drpy` 远程 JS 模块启用 15 分钟内存缓存、5 分钟 `404`/`410` 负缓存并静音 `console.log`/`print`；Type-3 脚本探测直接复用模块缓存，消除同一入口 JS 二次下载；切集与换线路复用同一回环代理与上游连接池；IPTV XMLTV 改为单遍流式解析。
- **稳定性与发布维护加固**：
  - 修复详情页点击「相近结果 (N)」后同帧读取已清空状态导致的空指针闪退。
  - 更换/移除片库或退出应用时通过共享取消域原子中止全部片库后台任务（首页扫描、搜索、追剧刷新与测速）。

## 下载与更新

- **macOS 13 及以上（按芯片分架构轻量包）**：
  - Apple Silicon（M 系列）下载 `xiaomu-0.9.9-arm64.dmg` 或 `xiaomu-0.9.9-macos-arm64.zip`。
  - Intel 下载 `xiaomu-0.9.9-amd64.dmg` 或 `xiaomu-0.9.9-macos-amd64.zip`。
- **Windows x64**：下载 `xiaomu-setup-0.9.9-amd64.exe`（内置 `mpv-2.dll`；因 `mygo-player v0.5.1` 暂仅提供 `windows-amd64` 动态库，本版暂不提供 Windows ARM64 安装包）。
- **应用内自动更新**：
  - 已安装 `v0.9.8`（macOS 分架构或 Windows x64）的用户可通过应用内「检查更新」直接升级至 `v0.9.9`。
  - 仍停留在 `v0.3.0–v0.9.7` 的旧版 macOS Universal 用户，本版继续随附 2 KB 固定桥接清单 `update-darwin-universal.json`，应用内更新会自动先升至 `v0.9.8` 桥梁版、重启后再自动升级至对应芯片的 `v0.9.9` 轻量单架构包。
- 全部安装包与签名更新包均附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时 SmartScreen 可能提示未知发布者。
