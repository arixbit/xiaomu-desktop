# 小幕 v0.8.7 · 弹幕与内网盘

播放片库剧集时，点控制栏“弹幕”或按 `D` 键即可开关弹幕。支持片源自带 `danmaku` 地址，未提供时自动使用[开源项目的公共弹幕服务](../danmaku.md)按片名和集数匹配，也可在“服务设置（可选）”填写自己的弹弹play兼容服务。切集和换源自动跟随当前分集，也可以修改片名或集数后按回车手动搜索。

弹幕支持滚动、顶部、底部模式，60fps 滚动、宽屏等速缩放与四向描边，暂停、拖动、倍速与全屏隐藏控件时保持同步。弹窗内可调字号、不透明度、滚动速度、显示区域、当前分集时间偏移（`-5s / -1s / +1s / +5s`）、三档密度（稀疏 / 适中 / 密集），支持屏蔽顶部/底部/彩色弹幕、自动合并 3 秒内相同刷屏（`×N`）、防挡底部字幕与自定义屏蔽词；进度条上方提供弹幕高能密度曲线。弹幕默认关闭，显示与屏蔽偏好只保存在本机。

侧边栏同时新增“内网盘”页，支持连接局域网 SMB/NAS 共享目录，直接浏览并播放 MP4 / MOV / M4V 视频，同时接入播放历史与续播。播放经本地随机令牌代理转发，停止播放或断开内网盘时自动撤销令牌并清理连接。

## 下载与更新

- macOS 13 及以上可下载 `xiaomu-0.8.7.dmg` 或 `xiaomu-0.8.7-macos-universal.zip`，两者均支持 Apple Silicon 和 Intel。
- Windows x64 使用 `xiaomu-setup-0.8.7-amd64.exe`，Windows ARM64 使用 `xiaomu-setup-0.8.7-arm64.exe`。
- 已安装 v0.8.6 及更早版本的用户可以通过应用内“检查更新”升级。安装包与签名更新包附有 `SHA256SUMS` 校验文件。

macOS 安装包使用本地 ad hoc 签名，尚无 Apple 公证。Windows 安装包未做 Authenticode 签名，首次打开时可能出现 SmartScreen 提示。
