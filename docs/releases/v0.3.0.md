# 小幕 v0.3.0

加入在线更新。v0.2.0 及更早版本需要手动下载安装一次本版，此后的版本可直接在 App 内更新。

## 更新内容

- 侧边栏与“小幕”菜单增加“检查更新”，使用原生中文更新窗口显示版本说明、下载进度及安装结果。
- App 启动后及运行期间每天检查新版本，可选择安装、稍后提醒或跳过。默认不自动下载安装，用户可在更新窗口自行开启。
- 更新包通过内置公钥进行签名校验，校验通过后安装，可选择重启生效；安装完成时保存播放历史。
- 发布流程同步提供签名更新包和清单。

## 下载与安装

- 要求 macOS 13+；Universal 同时包含 Apple Silicon 与 Intel。
- 下载 `xiaomu-0.3.0.dmg` 或 `xiaomu-0.3.0-macos-universal.zip`，将 `Xiaomu.app` 移到“应用程序”替换旧版。在线更新需要 App 所在目录可写。
- `SHA256SUMS` 可用于核对下载文件。`update-darwin-universal.json` 和 `.tar.gz` 附件供 App 更新器使用。
- 首版在线更新仍使用本地 App 签名，尚无 Developer ID 签名及 Apple 公证。首次打开若被拦截，确认下载来源后到“系统设置 → 隐私与安全性”选择“仍要打开”。

## 验证

- `go test ./...` 与 `go vet ./...` 通过。
- 使用独立临时 App 验证更新器：同版本不重复更新、篡改包被拒绝且原 App 不变、正常签名包完成下载并在进程退出后替换 App，替换后的代码签名校验通过。此验证不修改用户已安装的小幕。

原有导航、播放历史与兼容范围见 [v0.2.0](https://github.com/arixbit/xiaomu-desktop/releases/tag/v0.2.0)。Intel 尚未实机验证；小幕采用 CC BY-NC-SA 4.0，不内置片源或默认配置。
