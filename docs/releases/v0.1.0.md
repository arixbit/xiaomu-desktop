# 小幕 v0.1.0

首个公开版本。小幕是 macOS 原生影视聚合播放器，只提供播放工具，不内置片源、默认配置或真实片源地址。用户需自行导入配置或媒体链接。

## 下载与安装

- 系统：macOS 13 或更新版本。Universal 包含 Apple Silicon（arm64）与 Intel（x86_64）。Go 1.27.3 的最低系统要求为 macOS 13，本版不支持 macOS 12。
- 推荐下载 `xiaomu-0.1.0.dmg`，打开后将 `Xiaomu.app` 拖到“应用程序”。
- 也提供 `xiaomu-0.1.0-macos-universal.zip` 和 `SHA256SUMS`。下载后运行 `shasum -a 256 xiaomu-0.1.0.dmg`（ZIP 请替换文件名），与 `SHA256SUMS` 中对应行比对。
- 本版使用本地签名，尚无 Developer ID 签名及 Apple 公证。首次打开如被系统拦截，请确认下载来源后，在“系统设置 → 隐私与安全性”选择“仍要打开”。

## 本版功能

- 原生 Glass 片库、豆瓣热播、站点推荐、跨站搜索、结果来源筛选与分集播放。
- 支持 XML/JSON CMS、drpy2、基础 FongMi class 与通用 XBPQ 规则；支持带注释、尾逗号及图片封装的 TVBox 配置。
- 原生 AVPlayer 播放，提供进度、音量、倍速、全屏、分辨率显示与自动下一集；本机代理传递媒体请求头并改写 HLS 播放列表。
- CMS 网页解析、配置中的网页/JSON 解析器，以及隔离 WKWebView 动态取流。
- IPTV 支持 M3U/M3U8、TXT 和 TVBox 直播配置，包含分组、搜索、切台及备用线路切换。
- CMS 搜索和影片详情不依赖分类接口成功；搜索结果在内存中缓存 10 分钟，失败源冷却 30 秒，“重新加载”可立即重试。
- 配置地址仅保存在本机；程序、安装包及仓库不分发用户配置。

## 验证范围

- 完整 Go 测试与 `go vet` 通过，搜索缓存、取消和刷新路径通过竞态检查。
- 本机原生 AVPlayer 已验证本地生成的 H.264/AAC HLS：持续解码变化画面、播放进度推进，分片请求保留所需请求头。
- macOS Universal 构建与本地签名校验通过。Intel 版本已编译，尚未在 Intel Mac 上实机验证。
- 第三方站点的可用性受其接口、网络、编码和访问限制影响；测试通过不代表所有配置与片源都可播放。

## 已知限制

- 不执行 Android 专用 jar/Dex 爬虫或 Python 爬虫。依赖 Android 宿主或特殊加密能力的脚本仍可能不兼容。
- HTTP-FLV 转换、RTSP/RTMP、直播节目单及回看尚未实现；UDP/RTP 组播需用户自行转换为 HTTP。
- HEVC 和其他媒体格式取决于系统解码能力，尚未完成全面验证。
- 收藏、观看进度持久化及跨设备同步尚未提供。
