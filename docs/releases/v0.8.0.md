# 小幕 v0.8.0

加入追剧通知、本地视频打开、播放与搜索链接，以及系统“正在播放”和媒体键支持，同时修复这些入口与现有播放流程的衔接。

## 新功能与改进

- 追剧刷新发现新集时发系统通知，点击打开该剧详情；首次需要发送时才请求授权，拒绝后仍保留应用内的新集标记。
- 从 Finder 用小幕打开 mp4、mov、m4v、m3u8 文件，并记录在系统最近打开的项目。本地文件不进入追剧历史；默认打开方式由 macOS 设置决定。
- 支持 `xiaomu://play?url=...` 播放 HTTP/HTTPS 地址，以及 `xiaomu://search?wd=...` 搜索片名。
- 控制中心显示片名、分集和播放状态，媒体键支持播放／暂停及切换分集或直播频道。
- 详情页显示已知豆瓣评分，片源页可测速，播放页显示代理下载速度。

## 播放与启动修复

- 外部播放不覆盖原剧观看进度，并取消旧解析任务，避免旧分集抢回播放。
- 冷启动的搜索、通知等待配置恢复完成；取消或加载失败时丢弃过期跳转。
- 播放时点击追剧通知，先退出播放器再进入对应详情。
- 系统播放信息正确跟随分集、频道、倍速、进度跳转和播放结束；打开失败时清除旧信息。

## 安装与更新

支持 macOS 13 及以上，Universal 同时包含 Apple Silicon 与 Intel。可在应用内“检查更新”升级，或下载 xiaomu-0.8.0.dmg、xiaomu-0.8.0-macos-universal.zip 手动安装。

提供签名更新包、update-darwin-universal.json 和 SHA256SUMS。现有配置、追剧与历史数据保持兼容。App 沿用本地签名，尚无 Apple Developer ID 签名及公证。
