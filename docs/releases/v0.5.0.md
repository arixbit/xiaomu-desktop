# 小幕 v0.5.0

补齐片库 P2 体验并修复窗口无法拖动：搜索不用打全名，收藏上首页，全程可用键盘导航，窗口终于可以拖动。

## 更新内容

- **搜索联想**：顶部搜索框输入时下拉给建议，来源是本地搜索历史与已缓存的豆瓣热播，不新增联网。
- **首页收藏**：首页新增“我的收藏”横条，点海报进详情；没有收藏时不显示。
- **键盘导航**：方向键只移动不打开，回车进详情，Esc 返回上一页；搜索、豆瓣首页、站点浏览三个列表行为统一。
- **推荐排序**：无搜索词时豆瓣热播排最前；豆瓣 6 小时缓存不变。
- **窗口可拖动**：首页与播放页顶部新增拖动区，避开红绿灯按钮；全屏时隐藏；双击可最大化。

## 安装与更新

macOS 13+，Universal 同时包含 Apple Silicon 与 Intel。安装文件为 `xiaomu-0.5.0.dmg` 或 `xiaomu-0.5.0-macos-universal.zip`，附 `SHA256SUMS`。

本版沿用现有更新签名密钥，并提供签名更新包和清单。正式发布后，v0.3.0 及以上用户可从 App 内“检查更新”安装；v0.2.0 及更早版本需手动安装。App 仍为本地签名，尚无 Developer ID 签名或 Apple 公证。

## 验证与限制

- `go test ./...`、`go vet ./...` 与 `go test -race ./cmd/xiaomu ./internal/proxy` 通过（Linux 虚拟机）。
- 窗口拖动只通过 headless 测试验证：拖动条在顶部正确位置，不遮挡搜索框与播放页返回按钮，全屏时隐藏；真机上实际拖动仍需确认。
- 当前 MyGo 首次读取媒体信息仍可能同步阻塞界面；无上游响应的单次等待已限制为 30 秒。实际音频听感、长时间播放、睡眠唤醒和 Intel 实机仍待验证。
