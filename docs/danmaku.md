# 弹幕服务

小幕的弹幕测试版内置公共服务，用户无需填写地址、注册账号或准备 API 密钥。影视片源和 TVBox 配置仍由用户提供。

## 默认服务与来源

- 公共部署：`https://danmuapi-gamma-two.vercel.app`
- 地址出处：[Bear-biscuit/danmu_api_x 的项目主页](https://github.com/Bear-biscuit/danmu_api_x)。仓库采用 AGPL-3.0，项目的 `homepage` 字段指向上述部署。
- 上游项目：[huangxd-/danmu_api](https://github.com/huangxd-/danmu_api)。兼容弹弹play接口，支持按片名、集数搜索影视剧与动画，再下载对应弹幕。

小幕通过 HTTP API 使用该服务，没有打包或执行服务端代码，也没有内置其他应用的 AppId、私钥或访问令牌。2026-11-23 验证了匿名搜索、分集匹配、JSON 弹幕下载和原生 AVPlayer 叠加显示。公共部署由第三方维护，其可用性和片目覆盖会变化。

## 使用方式

播放片库影片时，打开“弹幕”并开启“显示弹幕”。加载顺序为：用户自定义服务 → 播放结果自带的 `danmaku` 地址 → 内置公共服务。设置了自定义服务时优先使用它；否则先使用片源自带的弹幕，没有地址才自动搜索公共服务。

片名和集数默认来自正在播放的分集。搜索服务附加的年份、类型和平台标签不影响同一版本的匹配；集名支持“第3集”“EP03”和“【平台】剧名第3集”等形式。同一版本由多个平台提供时采用服务返回的第一个结果；不同年份等有歧义的结果留给用户选择。

可以直接修改片名和集数，再点“搜索弹幕”选择结果；集数留空列出全部分集。手动选择后，同一影片的后续分集优先匹配该系列。切集、离开播放或关闭弹幕会取消旧请求。

“服务设置（可选）”允许填写其他兼容服务，清空后恢复默认行为。HTTP 失败和没有搜索结果会分别显示提示；弹幕失败不阻断视频播放。

## 数据与验证

弹幕默认关闭。开启公共服务搜索后，服务会收到片名、集数和弹幕分集 ID；媒体请求的 Cookie、Authorization 和用户的 TVBox 配置地址不会传给它。自定义服务地址与显示偏好只保存在本机。

常规 `go test ./...` 使用本地夹具，不请求公共弹幕服务。macOS 可显式运行真实联网与 AVPlayer 验证：

```sh
XIAOMU_NATIVE_MEDIA_DIR='<包含至少3秒 h264.mp4 的本地目录>' \
XIAOMU_DANMAKU_LIVE_TITLE='<要验证的片名>' \
XIAOMU_DANMAKU_LIVE_EPISODE=3 \
go test ./cmd/xiaomu -run '^TestNativeDanmakuLiveDefaultService$' -count=1 -v
```

测试使用本地生成的静音 H.264 视频验证叠加效果，弹幕由默认服务实时搜索和下载。测试片名从环境变量读取，不写入仓库，也不修改用户的片源或偏好。
