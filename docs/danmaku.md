# 弹幕服务

小幕内置国内直连弹幕，无需填写服务地址、注册账号、配置 API 密钥或开启代理，在国内网络环境下可直接获取常见剧集、电影、动漫与综艺弹幕；同时保留自定义弹弹play兼容服务入口。影视片源和 TVBox 配置仍由用户提供。

## 默认来源

未填写自定义弹幕服务时，小幕直接请求国内公开可匿名访问的接口，不经过境外中转节点，也不打包第三方服务端代码或私有凭证：

- 目录检索：360 影视公开搜索与分集接口（`api.so.360kan.com` / `api.web.360kan.com`）
- 弹幕拉取：腾讯视频（`dm.video.qq.com`）、爱奇艺（`pcw-api.iqiyi.com` / `cmts.iqiyi.com`）、优酷（`v.youku.com` / `acs.youku.com`）、芒果 TV（`pcweb.api.mgtv.com` / `galaxy.bz.mgtv.com`）与哔哩哔哩（`api.bilibili.com` / `comment.bilibili.com`）的公开弹幕接口

各平台公开接口由对应服务方维护，可用性与片目覆盖可能随平台调整而变化；超过单集 50,000 条上限时会按时间轴均匀抽样，避免影片后半段缺弹幕。

## 使用方式

播放片库影片时，打开“弹幕”并开启“显示弹幕”，或直接按 `D` 键快捷开关。加载顺序为：用户自定义服务 → 播放结果自带的 `danmaku` 地址 → 内置国内直连服务。设置了自定义服务时优先使用它；未设置时优先使用片源自带弹幕，若片源自带弹幕为空或请求失败，会自动回退到内置国内直连服务。

片名和集数默认来自正在播放的分集。搜索服务附加的年份、类型和平台标签不影响同一版本的匹配；季数支持中英文数字互认（如“第四季”与“第4季”）；集名支持“第3集”“第三期上”“EP03”“【平台】01 标题”以及“2026-10-10”等日期分期形式，单集电影支持匹配“正片”或片名。综艺会自动优先排序正片并过滤极短预告，正片与加更/纯享/上下期可自动消歧，无法唯一确定或仅按日期命名时保留候选列表交给用户选择；同名多版本会结合片源年份自动消歧，自动下载弹幕失败时也会保留已搜到的候选列表，方便直接改选其他平台或点击“重试”。

可以直接修改片名和集数，再按回车或点“搜索弹幕”选择结果；集数留空列出全部分集。手动选择后，同一影片的后续分集优先匹配该系列。控制栏按钮会实时提示当前状态（`加载中` / `开` / `待选` / `无弹幕` / `失败`），弹幕设置弹窗顶部开关下方会始终显示清晰状态提示与失败重试入口。切集、离开播放或关闭弹幕会取消旧请求。

“滚动速度”可设为 `0.25×–1.5×`，默认 `0.5×`（800px 基准宽度下横穿耗时从 8 秒延长到 16 秒），并按画面宽度自动等速缩放，保证小窗、全屏和宽屏下阅读速度一致。滚动弹幕以 60fps 从顶部第 0 行起排，顶部/底部固定弹幕独立分层并显示 4 秒，文字带四向描边以提升亮画面下的可读性。调整会立即生效，碰撞避让和显示时长同步更新；速度基于视频时间，暂停、拖动和倍速播放时继续保持同步。

播放剧集时可按 `D` 键快速开关弹幕；弹窗内的“时间偏移”支持按 `-5s / -1s / +1s / +5s` 微调当前分集弹幕对齐（切集自动重置），用于补偿不同片源片头差异。设置中支持切换弹幕密度（稀疏 / 适中 / 密集）、按类型屏蔽（顶部、底部、彩色弹幕）、自动合并 3 秒内相同刷屏弹幕（显示 `×N`）、防挡底部字幕以及自定义屏蔽关键词；播放点播剧集且开启弹幕时，进度条上方会显示弹幕高能密度曲线。所有显示与屏蔽偏好仅保存在本机。

“显示区域”限制弹幕从视频画面顶部向下覆盖的高度，范围为 `25%–100%`，默认 `50%`（上半屏）；视频黑边和播放控件不计入可绘制区域。文字大小继续由“字号”调节。速度和区域高度只保存在本机，旧版偏好文件会自动采用默认值。小窗口中的设置内容可以滚动，“完成”按钮固定在底部。

“服务设置（可选）”允许填写其他兼容弹弹play `/api/v2` 规范的服务（例如自建的 `danmu_api`），清空后恢复内置国内直连模式。HTTP 失败和没有搜索结果会分别显示提示；弹幕失败不阻断视频播放。

## 数据与验证

弹幕默认关闭。开启弹幕后，内置模式只会向上述公开接口发送片名及对应分集标识；媒体请求的 Cookie、Authorization 和用户的 TVBox 配置地址不会传给弹幕接口。自定义服务地址与显示偏好只保存在本机。

常规 `go test ./...` 使用本地夹具，不访问任何外部网络。macOS 可显式运行真实联网与 AVPlayer 验证：

```sh
XIAOMU_NATIVE_MEDIA_DIR='<包含至少3秒 h264.mp4 的本地目录>' \
XIAOMU_DANMAKU_LIVE_TITLE='<要验证的片名>' \
XIAOMU_DANMAKU_LIVE_EPISODE=1 \
go test ./cmd/xiaomu -run '^TestNativeDanmakuLiveDefaultService$' -count=1 -v
```

测试使用本地生成的静音 H.264 视频验证叠加效果，弹幕由内置国内直连服务实时搜索和下载。测试片名从环境变量读取，不写入仓库，也不修改用户的片源或偏好。
