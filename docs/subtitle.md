# 在线外挂字幕匹配

小幕在 `libmpv`（`mygo-player`）播放链路下支持内嵌字幕切换、本地外挂字幕加载与拖拽，并提供面向 4K 网盘原画及本地无字片的在线外挂字幕匹配能力。

## 字幕来源与约束

遵循小幕「不内置私有凭证、不内置影视片源」原则，在线字幕匹配采用分层公开协议：

1. **内置免登录哈希匹配（射手 / Shooter 公开协议）**
   - 接口地址：`https://www.shooter.cn/api/subapi.php`
   - 适用场景：本地视频文件（>= 8 KiB）。仅在本机计算 4 段 4 KiB 采样块的 MD5 哈希，连同**纯文件名**（剥离所有目录路径）提交匹配，不上传视频内容或本机完整路径。
2. **可选用户自填 Token 关键词搜索（伪射手 / ASSRT 开放 API）**
   - 接口地址：`https://api.assrt.net`
   - 适用场景：任意在线/网盘/本地影片按片名关键词搜索字幕。小幕**不内置**任何 ASSRT Token，由用户在「字幕设置」中自行填写个人 Token，仅保存在本机 `preferences.json`。

## 安全与缓存

- 下载限制单文件与压缩包上限为 10 MiB，仅接受 `http` / `https` 下载链接。
- 支持 `.srt` / `.ass` / `.ssa` / `.vtt` 明文字幕以及 `.zip` 压缩包（内存安全解压，跳过 `__MACOSX` 杂项并自动优先选取中文/双语字幕）。
- 下载结果缓存在系统临时目录下的 `xiaomu-subtitles` 中，不向任何外部服务发送用户的 TVBox 配置地址、网盘 Cookie 或观看历史。

## 离线测试

常规 `go test ./...` 使用本地 `httptest.NewServer` 与临时文件验证哈希算法、协议解析与 ZIP 择优解压，不访问外网。
